# Assistant — 你的全能 AI 工作助手

> 一款 AI 工作助手，帮你写文档、搜信息、写代码、发邮件、做表格……用说话的方式完成各种工作任务。支持桌面客户端和 Web 浏览器两种使用方式。

---

## 它能做什么？

Assistant 不只是一个聊天机器人。它可以**真正替你完成任务**：用自然语言告诉它你想做什么，它会自动调用各种工具，一步一步把事情做完。

比如：

- "帮我搜索最近一周的 AI 行业新闻，整理成一份 Word 文档"
- "读取桌面的销售数据表，生成一张趋势图，做成 PPT"
- "每天早上 9 点收集科技新闻，发到我的钉钉"
- "帮我写一封英文邮件，发给 john@example.com"

## 核心功能

### 🤖 AI 对话

和主流 AI 助手一样，支持多轮对话、实时流式回复。你还能看到 AI 的**思考过程**，了解它是怎么分析问题的。

**支持 13 家 AI 提供商，自由切换：**

| 国内 | 国际 |
|------|------|
| DeepSeek | OpenAI（ChatGPT） |
| 智谱 GLM | Anthropic（Claude） |
| 通义千问 | Google Gemini |
| 月之暗面 | OpenRouter |
| MiniMax | Ollama（本地模型） |
| 豆包、小米 | 自定义 API |

支持自己搭建的模型服务，也支持 OpenAI 和 Anthropic 两种协议格式。

---

### ⚡ AI 帮你干活（Cowork 模式）

这是 Assistant 最核心的功能。你描述任务，AI 自动执行——它会调用工具、运行命令、写代码、操作文件，全程你可以实时看到进度。

**每一步操作都需要你批准**，AI 不会"偷偷"做任何事。比如要删除文件或运行系统命令时，会弹窗让你确认，放心使用。

**两种执行环境：**

- **本地模式**：直接在你的电脑（或服务器）上执行，速度最快
- **沙盒模式**：在独立的虚拟机里运行，代码互不影响，更安全

**工作区文件浏览器：**

在 Cowork 界面右侧可以打开文件面板，实时查看 AI 正在操作的文件目录，支持上传、下载、新建文件夹、重命名和删除操作。

### 🗓️ 定时任务

让 AI 按计划自动工作，不用你守着。

- **每天早上 9 点**收集行业新闻
- **每周一**整理上周工作内容
- **每月 1 日**生成月度报告

支持按分钟、小时、天、周、月设置，也支持 Cron 表达式。任务完成后可推送通知到你的手机 IM 软件。

### 📱 手机远程控制（IM 集成）

在外出时，用手机发消息，AI 自动帮你完成任务并把结果回复给你。

**支持 5 个平台：**

| 平台 | 特点 |
|------|------|
| 钉钉 | 支持企业机器人，群聊/私聊 |
| 飞书 | 支持国内外版本（飞书/Lark） |
| Telegram | 国际用户友好，支持用户白名单 |
| Discord | 支持频道和私信 |
| 云信（NIM） | 私聊模式 |

用法示例：用手机在钉钉发一句"帮我查一下今天的天气和新闻"，几秒后 AI 就完成了，并把结果回复到你的钉钉。

### 🧠 记忆系统

AI 会记住你的个人信息和偏好，下次对话时自动应用，不用每次重复说。

**会记住什么：**
- 你叫什么名字、从事什么工作
- 你偏好的编程语言、写作风格
- 你的常用项目和文件路径
- 你对 AI 回复的格式要求

**如何添加记忆：**
```
记住：我是前端工程师，主要用 React
记住：回复时用中文，代码注释用英文
```

也可以在记忆管理页面手动添加、编辑、删除记忆条目。

## 两种使用方式

| 模式 | 适用场景 | 说明 |
|------|---------|------|
| **桌面客户端** | 个人使用 | 安装到电脑上，支持 macOS、Windows、Linux |
| **Web 模式** | 团队共享 / 服务器部署 | 部署到服务器，通过浏览器访问，无需安装客户端 |

Web 模式功能完全对等，所有 Cowork、技能、IM 集成、定时任务等功能均可在浏览器中使用。

## 数据安全与隐私

- **全本地存储**：所有对话、配置、记忆均保存在本机 SQLite 数据库，不上传云端
- **API Key 加密**：导出配置时自动加密，防止密钥泄露
- **权限审核**：AI 执行任何系统操作前必须经过你的确认
- **沙盒隔离**：可选在虚拟机中运行代码，与本地系统完全隔离

## 快速上手

1. **配置 AI 模型**：在设置 → 模型中添加你的 API Key
2. **选择技能**：在 Cowork 设置中启用你需要的技能
3. **开始对话**：新建一个 Cowork 会话，输入你的任务
4. **审批操作**：AI 执行前会弹窗确认，点击"允许"即可
